                    Configuration as code
                    
Your server settings live in your repository

                    
Put a cipi.yml next to your code: PHP version, workers, scheduler, domains, health check, backups, deploy steps. It ships with each release, gets reviewed in pull requests, and the server shows the plan before applying anything.

                    
    
                        
  • Plan, then apply. Every change is listed first and applied all or nothing.
    • 
                        
  • Safe to accept from Git. A file can't create apps, touch other apps or run a shell.
    • 
                        
  • No secrets in Git. Required variables are names; credentials stay on the server.
    • 
                        
  • One repo, every environment. cipi-staging.yml for staging, cipi.yml for production.
    • 
                    

                    
How cipi.yml worksCopy a recipe

                

                

                    
cipi.yml


version: 1
app:
  php: "8.6"
  aliases: ["www.shop.example.com"]
workers:
  horizon: true
  reverb: true
schedule: true
health:
  url: "https://shop.example.com/up"
  rollback_on_unhealthy: true
backup:
  profiles:
    - { name: shop-nightly, every: 1d, destinations: [s3] }

                    
cipi.yml
$ cipi yml plan shop
$ cipi yml apply shop
$ cipi yml auto shop on

Questions people ask before installing

            

                
What is Cipi?
Cipi is a Laravel-first, open-source deploy CLI that also supports static sites and generic PHP apps. A single command installs a complete production stack (Nginx, PHP-FPM or Laravel Octane, MariaDB, Valkey, Supervisor) on any Ubuntu VPS.

                
Is Cipi free?
Yes. Cipi is 100% free and open source under the MIT license. You self-host it on your own server with no subscription or per-server fees.

                
How do I install Cipi?
Run a single command on a fresh Ubuntu VPS: wget -O - https://cipi.sh/setup.sh | bash. It installs and configures the full LEMP production stack automatically. The quickstart walks through every step.

                
Is Cipi an alternative to Laravel Forge?
Yes. Cipi is a free, self-hosted, open-source alternative to Laravel Forge and similar deployment tools, giving you full control over your servers with zero recurring cost. See the Laravel Forge comparison.

                
Which servers does Cipi support?
Cipi runs on any Ubuntu VPS from providers like DigitalOcean, Hetzner, Vultr, Linode, AWS, and more, turning a single server into a multi-app LEMP hosting platform.

                
Does Cipi support Laravel Octane?
Yes. Cipi runs Laravel Octane on FrankenPHP natively: create Octane apps with cipi app create --octane or convert existing apps with cipi app convert --to=octane, running alongside classic PHP-FPM apps on the same server.

                
Does Cipi have a web control panel?
Yes, optionally. Cipi is CLI-first, but cipi gui yourdomain.com installs a free, self-hosted web dashboard that manages one or more Cipi servers from the browser — apps, databases, SSL, deploys and logs.

                
Does Cipi send my data to external services?
No. Cipi is self-hosted and has no telemetry or phone-home: it runs on your VPS and never sends your apps, domains, keys or database credentials anywhere. It is open source (MIT), built in the EU, and stores configs, tokens and keys encrypted with AES-256-CBC through the Vault.

                
Can AI agents manage a Cipi server?
Yes. Cipi ships a dual MCP (Model Context Protocol) server, so MCP-compatible IDEs and AI agents can create apps, run deployments, manage SSL and databases through a structured API. See the MCP server docs.

                
Is it safe for production?
Yes. Each app is isolated (own Linux user, PHP pool, database user and Valkey), PHP is patched every night, the firewall and Fail2ban are on by default, secrets are encrypted at rest, and deploys switch atomically with rollback. See the security model.

                
How big a server do I need?
2 vCPU and 4 GB of RAM comfortably run several Laravel apps; 1–2 GB is enough for a small one. Any provider works: Hetzner, DigitalOcean, AWS and more.

                
Can I keep server settings in Git?
Yes, with cipi.yml: PHP version, workers, domains, backups and deploy steps live next to your code, are reviewed in pull requests and applied all or nothing.

                
Is there a lock-in?
No. Your apps run on a standard Ubuntu stack (Nginx, PHP-FPM, MariaDB or PostgreSQL). You can move them anywhere with a Git checkout and a database dump.

                
Where do I hear about new releases?
On the Telegram channel: releases and security notes first. Every release is also on GitHub and in the history.
