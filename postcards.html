How it works

  1. You send the form. Netlify, which hosts this site, filters spam before anything else happens.
  2. A person reads it. Each postcard becomes a pull request in the website repository. Nothing is published automatically.
  3. It goes on the wall. Once approved, it shows up here within a few minutes.

Links, HTML and addresses are refused, and nothing you didn't type is published. Want to know more about Cipi first? Start from the 15-minute guide.

Questions

Who can send a postcard?

Anyone who runs Cipi somewhere: a production server, a side project, a homelab box. One server is enough.

Why isn't my postcard on the wall yet?

Every postcard is read by a person before it goes up, so it can take a few days. If it isn't there after a week, it was probably caught by the spam filter: send it again or say hi on Telegram.

What gets published?

Only what you see on a card: your name (or Anonymous), your city if you give one, the provider, the region, the number of apps and the message. Nothing else is collected.

Can I add a link to my project?

No. Links and addresses are removed by design, which keeps spam off the wall. Mention the project by name instead.

Can I change or remove my postcard?

Yes. Open an issue on GitHub or write on Telegram and it will be changed or removed.

Where is the data stored?

Submissions are stored by Netlify, which hosts this site. Approved postcards are added to a public file in the website repository. Submissions that are not published are deleted.

My provider isn't in the list.

Pick Other and write the provider in your message. If several people use it, it will be added to the list.

Try it on your own server

Free and open source. One command on a fresh Ubuntu 24.04 or 26.04 VPS.

wget -O - https://cipi.sh/setup.sh | bash
