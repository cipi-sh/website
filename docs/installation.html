Install Cipi

Server requirements, SSH keys, the installer and first login.

Start here

One command turns a fresh Ubuntu server into a hardened, production-ready host. This page covers what the server needs, the SSH key, the installer and how you log in afterwards.

Requirements#

NeedWhy
Ubuntu 24.04 or 26.04 LTS, fresh installCipi owns the whole stack; an existing web stack would conflict
Full VM or bare metal (KVM, VMware, Hyper-V, Xen HVM)Cipi tunes the firewall, swap and kernel, which needs its own kernel
Public IPv4, ports 22, 80, 443 openLet's Encrypt and your visitors must reach the server
Root or sudo accessTo install packages and harden SSH

Works on DigitalOcean, Hetzner, AWS EC2, Vultr, Linode, Google Cloud, OVH, Scaleway and any KVM or bare-metal host. The installer checks the environment first: in a container (Docker, LXC, OpenVZ, WSL, OrbStack…) it stops and tells you why.

Cipi is for real servers, not laptops. A local VM or container may look like it works, but certificates, domains and deploys will not. See Why not local?.

Install#

  1. SSH keyon your laptop
  2. Installeron the server
  3. Unattendedfor scripts and images
  4. Hardeningwhat gets secured
  5. Log inas cipi, credentials saved
The installer, start to finish
$ wget -O - https://cipi.sh/setup.sh | bash

1. Get your SSH public key#

On your computer (not the server), print your public key, or create one if you have none:

bash
cat ~/.ssh/id_ed25519.pub                       # existing key
ssh-keygen -t ed25519 -C "you@example.com"     # create one (Enter = default path)

Copy the whole ssh-ed25519 AAAA… comment line. Only the .pub file is public; never paste the private id_ed25519.

2. Run the installer on the server#

bash
ssh root@your-server-ip
wget -O - https://cipi.sh/setup.sh | bash

On AWS, log in as ubuntu and run sudo -s first. The installer then:

  1. Asks for your public key (and any more: a second laptop, a colleague) before installing anything.
  2. Shows its plan: IP, OS, SSH access, stack, passwords. Answer n and nothing has changed.
  3. Installs Nginx, PHP, MariaDB, Valkey, Supervisor, Composer, Deployer, Certbot, UFW and Fail2ban, and hardens SSH.
  4. Prints the credentials (root, MariaDB, Valkey) and waits until you confirm you saved them.
  5. Offers the optional extras: a Git provider token (so deploy keys and webhooks are set up for you), the panel API and the web panel.

Unattended install#

Pass the key in SSH_PUBKEY (several keys: one per line). Without a terminal the installer asks nothing.

bash
SSH_PUBKEY="ssh-ed25519 AAAA..." wget -O - https://cipi.sh/setup.sh | bash

What the installer secures#

AreaSetting
SSHRoot login off; cipi user with key only; 3 attempts, 20 s grace; X11 off
FirewallUFW allows only 22, 80, 443
Brute forceFail2ban with progressive bans
PatchesUnattended security upgrades
SecretsRoot, database and Valkey passwords are random and stored encrypted (AES-256) in /etc/cipi/server.json
LogsRotation and retention for app, security and HTTP logs (Log retention)

Log in after the install#

WhoHow
You (admin)ssh cipi@server with your key, then sudo cipi … (no password)
RootFrom the cipi session: su root with the root password from the summary
An appssh myapp@server with the app's password, or su - myapp as root
bash
ssh cipi@your-server-ip
sudo cipi status          # any cipi command, no password
su root                   # full root shell when you need one

Lost the credentials? sudo cipi credentials prints them again; sudo cipi credentials export writes a CSV your password manager can import.

Common problems#

ProblemFix
Installer refuses the OSReinstall the VPS with plain Ubuntu 24.04 or 26.04 LTS
Pasted key refusedPaste the public key (.pub), one line starting with ssh-ed25519 or ssh-rsa
Can't log in after the installRoot login is disabled: ssh cipi@IP. Lost the key? Use the provider's web console
Install interruptedRun the same command again; steps already done are skipped

Questions#

QuestionAnswer
Can I install on a server with other software?No. Cipi needs a fresh server: it configures Nginx, PHP, users and the firewall its own way.
Which size?1 GB RAM works for a small app; 2–4 GB is comfortable for several.
Where are the credentials?Printed at the end of the install, once. Save them in a password manager.
