Companion tools

Cipi deploys and runs your apps. It does not try to be an exception tracker, an analytics suite or an object store as well: those are separate jobs, better done by separate tools. The projects below cover the gaps around a Cipi server. They come from the same author, are open source under the MIT licence, and are all optional — Cipi does not depend on any of them.

Around the server

Tool What it does With Cipi
conn SSH connection manager: a lightweight Bash tool that saves connections under aliases and connects with conn to <alias>. Runs on your machine. Keep one alias per server for the cipi admin user and one per app user, instead of remembering hosts and ports.
Johnny S3-compatible object storage on your own VPS, powered by Garage and secured by Caddy, with automated backups, a web panel, a CLI and a REST API. Put it on a separate VPS (it brings its own Caddy), then use it as an S3-compatible destination for cipi backup or as a Laravel filesystem disk — off-site, and still on infrastructure you own.

Monitoring and analytics

Tool What it does With Cipi
Boogle Self-hosted exception tracker and uptime monitor for Laravel: ingests errors from your apps, groups issues, sends digests and watches services. cipi monitor watches the server and cipi health one URL per app; Boogle adds the application view — exceptions and uptime seen from outside. Error payloads stay on your infrastructure.
IndieStats Privacy-friendly, self-hosted web analytics on Laravel: real-time dashboards, filters, country map, ASN detection, Excel export — no cookies, no consent banner. A Laravel app like any other: deploy it with cipi app create on a subdomain and track every site on the server without sending visitor data to a third party.

Application security

Tool What it does With Cipi
Checkpoint Laravel security audit in one Artisan command: known CVEs in dependencies, leaked secrets and injection risks, with CI support and custom checks. Cipi hardens the server; Checkpoint checks the code. Run it in the pipeline before the deploy, so a vulnerable release never reaches the server.
Hackly Authorized attack-surface and application security scanning: inventory targets, verify DNS ownership, scan linked GitHub repositories (Laravel/PHP SAST and SCA), review findings in a Filament panel. A continuous vulnerability view across all your projects and domains. Built on Laravel and Filament, so it can run on a Cipi server itself. Its findings sit well next to a cipi compliance report.

Building Laravel apps

Tool What it does With Cipi
init One command to scaffold a complete Laravel + Filament local stack on macOS, with Docker, SSL and a real *.127001.it subdomain. Start the project locally with init, push it to Git, and let Cipi take it from there — Git auto-setup, cipi.yml, zero-downtime deploys.
Larapilot Spec-driven AI product workflow for Laravel, via Laravel Boost: from product idea to reviewed code, with personas, skills and optional forge and chat notifications. Larapilot shapes the code; the Cipi Agent MCP server and the panel API let the same AI tooling see and operate the running app.
