Security

Cipi Agent uses defense in depth: each feature has its own Bearer token and can be toggled off independently. When disabled, routes return 404 (hidden, not 403).

Token isolation

Feature Token variable Endpoint
Webhook deploy CIPI_WEBHOOK_TOKEN POST /cipi/webhook
Health check CIPI_HEALTH_TOKEN (fallback: webhook token) GET /cipi/health
MCP server CIPI_MCP_TOKEN POST /cipi/mcp
DB anonymizer CIPI_ANONYMIZER_TOKEN POST /cipi/db, POST /cipi/db/user
Panel tools (optional) CIPI_TOKEN — Sanctum token from cipi api token create Outbound, to the panel API via cipi/sdk

Webhook verification

  • GitHub — X-Hub-Signature-256 HMAC-SHA256 (X-Hub-Signature SHA-1 legacy)
  • Bitbucket — X-Hub-Signature sha256= HMAC
  • GitLab and Azure DevOps — X-Gitlab-Token header comparison
  • Gitea — X-Gitea-Signature HMAC-SHA256

All comparisons are constant-time. What the agent writes about a deploy (actor, commit, delivery id, IP) is recorded by Cipi as a claim in the audit ledger, never as a fact.

MCP safety

  • Blocked Artisan commands and SQL statements (see MCP server), one statement per call, reads capped at CIPI_MCP_MAX_ROWS, optional read-only mode (CIPI_MCP_DB_WRITE=false)
  • Secret redaction in logs and command output (CIPI_MCP_REDACT)
  • Origin validation against the app host (CIPI_MCP_ALLOWED_ORIGINS), 405 on GET/DELETE, no sessions to hijack
  • Tool failures are reported with isError, protocol errors with the JSON-RPC codes the clients expect; the file paths cipi_yml may read are confined to the app and its home

Anonymizer safety

  • Config outside the repository (/home/{app_user}/.db/, 0640), validated before a job is queued
  • Database passwords via MYSQL_PWD / PGPASSWORD, never on the command line; the original dump is deleted right after processing; outputs are 0600
  • Signed, time-limited download links (signed middleware); downloads confined to storage/cipi

Source code and releases: github.com/cipi-sh/agent (MIT).

ENV Variables

These variables are automatically injected by Cipi into the app's .env during cipi app create. Toggle optional features with php artisan cipi:service {type} --enable|--disable or set them manually.

Variable Description Default
CIPI_WEBHOOK_TOKEN Secret for webhook authentication (GitHub / Bitbucket / Gitea HMAC, GitLab / Azure token) auto-generated
CIPI_APP_USER Linux username for this app (paths, deploy trigger, logs) auto-set
CIPI_HOME Override the app home directory /home/<app_user>
CIPI_PHP_VERSION PHP version reported in the health check and used by cipi:yml generate system PHP
CIPI_DEPLOY_SCRIPT Path to Deployer config ~/.deployer/deploy.php
CIPI_DEPLOY_BRANCH Branch that triggers a deploy (empty = any branch). Written by Cipi since 5.7.2 empty
CIPI_ENV The app's environment label (cipi app create --env, Cipi 5.8.0+), reported by cipi:status, app_info, deploy_status, the webhook answer and the health report (agent 2.1.0); the server uses it to pick cipi-<env>.yml production
CIPI_ROUTE_PREFIX URL prefix for all agent routes cipi
CIPI_LOG_CHANNEL Laravel log channel for deploy events null
CIPI_HEALTH_CHECK Enable /cipi/health true
CIPI_HEALTH_TOKEN Bearer token for health (falls back to webhook token) none
CIPI_MCP Enable /cipi/mcp false
CIPI_MCP_TOKEN Bearer token for MCP none
CIPI_MCP_ALLOWED_ORIGINS Browser origins allowed on the MCP endpoint, comma-separated (* = any) the app host
CIPI_MCP_DB_WRITE Allow INSERT / UPDATE / DELETE through db_query true
CIPI_MCP_MAX_ROWS Default row cap for db_query (max 500) 100
CIPI_MCP_REDACT Redact common secrets in logs and command output sent over MCP true
CIPI_ANONYMIZER Enable anonymizer at /cipi/db false
CIPI_ANONYMIZER_TOKEN Bearer token for anonymizer none
CIPI_ANONYMIZER_CONFIG Explicit path of anonymization.json ~/.db/anonymization.json
CIPI_ANONYMIZER_TTL Minutes a download link stays valid 15
CIPI_MYSQLDUMP / CIPI_PG_DUMP Dump binaries, when not on PATH from PATH
CIPI_PANEL Expose the panel_* MCP tools when cipi/sdk is installed and configured true
CIPI_PANEL_APP App name on the panel CIPI_APP_USER
CIPI_BASE_URL / CIPI_TOKEN Panel API URL and Sanctum token, read by cipi/sdk none
Use php artisan cipi:generate-token {type} to generate tokens for mcp, health, or anonymize. Use php artisan cipi:service {type} --enable|--disable to toggle services — the command updates your .env in place.
