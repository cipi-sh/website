Choosing Cipi

Cloudflare Zero Trust vs Tailscale vs NetBird for your servers

What each one is for — Cloudflare Tunnel publishes sites to visitors, a Tailscale or NetBird mesh is the private way in for the people who run the server — how they differ on SSH, the panel, databases, deploys, self-hosting and cost, and how to combine them on one Cipi server.

By Andrea PollastriUpdated November 28, 20263 min read

Share

"Zero Trust" covers two different jobs, and the three tools Cipi manages split along that line:

  • Cloudflare Tunnel (with Access) is about visitors: it publishes your sites through Cloudflare, so the server needs no open port, and puts a login in front of what should be private.
  • Tailscale and NetBird are about you: a private network on which your laptop, your team and your CI reach the server — SSH, the panel, a database — while the public ports close.

The combined setup#

The setup with the least exposed:

bash
# visitors: sites through Cloudflare, 80/443 closed to everything else
sudo cipi zt token set --token=CF_API_TOKEN --account=ACCOUNT_ID
sudo cipi zt enable
sudo cipi zt hostname add shop
sudo cipi zt lock http --yes
# people: SSH over Tailscale, 22 closed to the world
sudo cipi zt tailscale enable --tags=cipi
ssh cipi@100.101.102.103            # once, over the mesh
sudo cipi zt tailscale lock ssh

The two sides know each other: a port stays closed while either holds it, cipi firewall status says who holds each one, and unlock on one side tells you if the other still keeps it closed. The panel's Zero Trust tab shows both — Cloudflare's tunnel read-only, the mesh managed.

What none of them replaces#

Key-only SSH, Fail2ban, per-app isolation, updates and backups stay what they are. A mesh or a tunnel reduces who can knock; it doesn't change what's behind the door. And keep a way in that depends on neither — your provider's web console.

Questions

Can I use both?

Yes, and it's often the best setup: sites through the Cloudflare Tunnel with 80/443 closed, SSH and the panel over the mesh with 22 closed. Cipi keeps a port closed while either side holds it.

Which is simplest?

For SSH only, a mesh: join, sign in, lock. For public sites behind a CDN and WAF with no open port, the tunnel.

Which keeps working if the vendor is down?

A mesh keeps existing connections when its coordination server is down; a self-hosted one (Headscale, NetBird) depends on nobody. A tunnel needs Cloudflare up, as do visitors anyway behind Cloudflare.

Which sees my traffic?

Cloudflare terminates TLS for the sites it proxies. A mesh is end-to-end WireGuard between devices; the vendor only coordinates (or relays encrypted packets).

Does Cipi manage all three?

Yes: cipi zt for Cloudflare, cipi zt tailscale and cipi zt netbird for the mesh — the mesh from the web panel and the API too.
