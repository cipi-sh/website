VPS, SSH and DNS for Laravel developers who never ran a server

The words and the three skills you need before deploying to your own server, explained from zero: what a VPS is, choosing one, creating an SSH key, logging in, pointing a domain with DNS records, checking it worked, and what Cipi takes care of so you don't have to.

By Andrea PollastriUpdated November 23, 20263 min read

Share

Deploying to your own server sounds harder than it is. You need three skills: get a server, log in with SSH, and point a domain at it. This guide explains each from zero, then hands over to the first deploy guide.

Key ideas, in plain words#

TermMeaning
VPSA virtual private server: a slice of a physical machine you rent by the hour or month, with its own IP and full control
Ubuntu LTSThe Linux version Cipi runs on (24.04 or 26.04). LTS = 5 years of security updates
IP addressThe server's number on the internet, e.g. 203.0.113.10
SSHAn encrypted way to log in and type commands on the server
SSH keyA pair of files: the private one stays on your laptop, the public one goes on the server. Safer than a password
DNSThe internet's phonebook: turns shop.example.com into an IP
A recordA DNS entry: "this name → this IPv4 address"
Step 1 of 5Your laptop

You create an SSH key on your laptop. The private half never leaves it.

Step 2 of 5VPS

You rent a VPS with Ubuntu LTS and a public IP, giving the provider your public key.

Step 3 of 5Cipi

One command installs Cipi and the whole stack.

Step 4 of 5Domain

At your DNS provider, an A record points your domain at the server's IP.

Step 5 of 5Visitors

Visitors reach your app over HTTPS.

2. Create an SSH key#

On macOS, Linux or Windows (PowerShell), the same command:

bash
ssh-keygen -t ed25519 -C "you@laptop"
# press Enter for the default path, then choose a passphrase
cat ~/.ssh/id_ed25519.pub
ssh-ed25519 AAAAC3Nza… you@laptop
~/.ssh/
  id_ed25519        ← private: never share, never upload
  id_ed25519.pub    ← public: paste it into the provider

Paste the public line into the provider's "SSH keys" field when you create the server.

3. Log in#

bash
ssh root@203.0.113.10

The first time, SSH asks whether you trust the server's fingerprint: type yes. You're in when the prompt changes to root@…. Now install Cipi (installation):

bash
wget -O - https://cipi.sh/setup.sh | bash

Early on, the installer asks for the public key that will open the cipi user: paste the same id_ed25519.pub line (you can add a second machine's key too). After the install, root login is disabled. From then on you log in as cipi:

bash
ssh cipi@203.0.113.10

Make it shorter with an entry in ~/.ssh/config:

text
Host shop
  HostName 203.0.113.10
  User cipi

Then ssh shop is enough.

4. Point your domain#

At your registrar or DNS provider (Cloudflare, Namecheap, OVH…), add:

TypeNameValueTTL
Ashop (or @ for the bare domain)203.0.113.10Auto / 300
Awww203.0.113.10Auto / 300
AAAAsame namesthe server's IPv6, if it has oneAuto

Check it from your laptop:

bash
dig +short shop.example.com
203.0.113.10

On Cloudflare, keep the cloud grey ("DNS only") until the certificate is issued, then you can turn the proxy on with SSL/TLS Full (strict).

ProblemFix

Connection timed outWrong IP, or the provider's firewall blocks 22: allow 22, 80, 443

Questions

Do I need to know Linux?

Very little. You need to log in with SSH and paste commands. Cipi does the system administration: packages, firewall, users, PHP, Nginx, certificates, patches.

How big a server do I need?

For one or a few Laravel apps, 2 vCPU and 4 GB of RAM is comfortable. 2 GB works for a small app. You can resize later at most providers.

Is a VPS secure?

It's as secure as its configuration. Cipi sets key-only SSH, a firewall with only 22, 80 and 443 open, Fail2ban, automatic security patches and one isolated user per app.

What if I lose my SSH key?

Keep a second key (another laptop) or use the provider's web console to add a new one. That's why Cipi refuses to remove your last key.

How long does DNS take?

Usually minutes. Some networks cache old answers for up to the record's TTL (often an hour). Use dig to check what the world sees.

Is a VPS cheaper than a PaaS?

Usually much cheaper for the same resources, with no per-seat or per-app fees. You pay the provider; Cipi is free.

What if a step fails?

Read the troubleshooting table above first. Then check the matching docs page, open a GitHub issue, or ask in the community. Most commands print the fix when they refuse something.
